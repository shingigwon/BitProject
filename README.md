# 🤖 AI 기반 코딩 챗봇  
> 교내 특별과정 비트 고급과정 (2022.12 ~ 2023.02)

---

## 📌 프로젝트 소개
코딩 입문자와 구현 능력이 부족한 사용자가  
AI를 통해 코드 작성 방향을 제안받고 문제 해결을 지원받을 수 있도록 개발한 챗봇 서비스입니다.

---

## 🚀 주요 기능
- 사용자 질문 기반 코드 생성 및 방향 제시
- AI 모델을 활용한 자연어 기반 코드 추천
- 클라이언트-서버 구조 기반 실시간 응답 처리

## ⚙️ Tech Stack
- Backend: C#, WCF
- AI Server: Python
- Database: MSSQL

---

## 🙋‍♂️ 담당 역할
- WCF 기반 웹 서비스 서버 구현 (클라이언트-서버 통신 처리)
- SQL 저장 프로시저 설계 및 데이터 처리 로직 구현
- Python 기반 AI 모델 서버 연동 및 응답 처리 로직 구현
